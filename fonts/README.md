# Γραμματοσειρές / Fonts

## Cocomat Pro — προς αντικατάσταση

Ο ιστότοπος είναι ήδη καλωδιωμένος για **Cocomat Pro**. Δεν συμπεριλαμβάνονται
αρχεία γραμματοσειράς επειδή τα διαθέσιμα αντίγραφα είναι **TRIAL** εκδόσεις και
η άδειά τους δεν επιτρέπει χρήση σε ιστοσελίδα.

Μόλις αποκτηθεί webfont άδεια, τοποθετήστε σε αυτόν τον φάκελο
(`public/fonts/`) τα παρακάτω αρχεία **με ακριβώς αυτά τα ονόματα**:

```
CocomatPro-Light.woff2     (300)
CocomatPro-Regular.woff2   (400)
CocomatPro-Medium.woff2    (500)
CocomatPro-Bold.woff2      (700)
```

Δεν χρειάζεται καμία άλλη αλλαγή — οι `@font-face` δηλώσεις υπάρχουν ήδη στο
`src/styles/fonts.css` και η Cocomat Pro είναι πρώτη στο `--font-ui` stack.

Αν η άδεια καλύπτει μόνο κάποια βάρη, ανεβάστε όσα έχετε· τα υπόλοιπα
πέφτουν αυτόματα πίσω στο fallback.

### Μετατροπή σε woff2

```bash
# με το woff2 CLI (brew install woff2)
woff2_compress CocomatPro-Regular.ttf
```

## Προσωρινό fallback

Μέχρι τότε χρησιμοποιείται **Manrope** (Google Fonts, πλήρης ελληνική κάλυψη,
γεωμετρικός χαρακτήρας κοντά στη Cocomat Pro).

## Bona Nova

Φορτώνεται από Google Fonts με ελληνικό subset — ταυτίζεται με την έντυπη
ταυτότητα (κάρτα / πινακίδα). Δεν απαιτείται ενέργεια.
